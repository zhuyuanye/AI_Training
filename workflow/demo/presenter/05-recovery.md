# 展示兜底｜静态分享

现场不依赖 Agent 或测试环境。主要处理阅读、时间和讨论节奏。

| 情况 | 处理 |
|---|---|
| Markdown 表格太长 | 只展开重点行；每页末尾的讲解检查点可直接讲 |
| HTML 不便打开 | 展示 [BA 08](../../examples/BA/08-generate-html-prototype.md) 的三个状态说明 |
| 没时间讲 36 步 | 按 [60 分钟安排](01-runbook.md)合并阶段；全部样例课后发 |
| 学员觉得预设口径不同于自己业务 | 说明产品可以选择另一口径，但必须同步 DEC、AC、原型和测试，不能只改单份文档 |
| 学员追问“这是你们真实项目吗” | 明确是虚构 Java／Vue 教学上下文，没有读取或修改业务应用 |
| 学员想看真实执行截图／Trace | 说明本次没有真实执行；展示证据清单的用途，不补造文件 |
| 模拟全绿被误认为可以上线 | 展示 [测试报告](../../examples/TEST/12-produce-test-conclusion.md)，指出 TC-16 阻塞与真实执行为 0 |
| Skill 用法引出工具故障排查 | 本次只讲产物与验证方式；课后在实际项目核对发现、加载和权限 |

不要临时把演示改成未准备的真实系统操作。课后实践入口是[原分步提示词](../../README.md)，样例里的日志、接口与数据不能当真实执行输入。
