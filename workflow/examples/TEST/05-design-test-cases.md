完整 16 项样例见 [TC-v1](../reference/test-cases.md)。最终展示表已补入 CODE-v1 的教学接口绑定，业务期望不变。

重点展示 TC-05：
- 前置：有权限管理员；历史用户邮箱为空；显示名为“历史用户”；记录数据快照。
- 输入：编辑保存只提供新显示名，不提供 email。
- 动作：提交保存，再查询该用户。
- 预期：拒绝并识别邮箱问题；显示名仍为“历史用户”，邮箱仍为空。
- 来源：AC-01/04/06。
- 独立性：该用例来自“编辑保存必须补邮箱”和“失败不改数据”，不是因为已经看到某段 if 代码。

覆盖结构：空值等价类、首尾清理、内部字符、历史操作、权限、失败不写入、UI 纠正流程、范围外影响。
保留 TC-16：旧格式／唯一性完整回归资料不足，状态“阻塞”，不填假预期。
