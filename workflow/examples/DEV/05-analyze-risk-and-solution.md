## 输出产物示例

### dev/solution.md

方案 SOL-v1：
1. Vue 管理表单增加必填和历史编辑提醒；保留旧格式提示。
2. AdminUserService 的新增与编辑均调用管理端必填规范化规则；任何写入前失败。
3. 管理端专用 AdminEmailPolicy 委托旧格式检查，不在共享 User 实体上增加全局非空约束。
4. 保存规范化后的邮箱，不拼接内部字符，不自动小写化。

| 风险 | 验证 |
|---|---|
| 页面挡住但直接 API 可绕过 | 新增／编辑省略、null、空串、纯空白矩阵 |
| 错误请求部分更新显示名 | 保存前后快照对比 |
| 历史登录被阻断 | 历史空邮箱用户登录／查询 |
| 共用对象波及其他入口 | 对照调用图、diff 与范围外代表操作 |

不选“全局实体加非空”：可能影响个人资料／导入，超出 DEC-08。
无需数据库回填或 schema 非空改造；持久层必须允许未触发编辑的历史空数据继续存在。
BLOCK-01 保留；不发明旧规则明细。
