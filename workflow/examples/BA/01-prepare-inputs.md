# BA 01｜整理输入：输入输出示例

[对应提示词](../../BA/01-prepare-inputs.md) · 实际工作模式：**Plan**

> 合成教学样例，用于静态讲解；不是已执行记录或真实产品确认。

## 输入示例

给 Agent 的材料：
- [现有系统说明](../../demo/inputs/01-current-system.md)：管理端已有新增、编辑；案例中邮箱原来可空。
- [会议转写](../../demo/inputs/02-teams-transcript.md)：保留相对时间与发言角色。
- 需求编号 REQ-DEMO-EMAIL-001；本轮只盘点输入，不输出完整方案。

## 输出产物示例

### ba/input-inventory.md

| 材料 | 可用内容 | 状态／缺口 |
|---|---|---|
| 现状说明 | 页面已有邮箱、历史账号可为空 | 合成业务设定，未核对源码 |
| Teams 转写 | 新增必填意图、编辑与空白等问题 | 合成转写，有时间戳 |
| 当前页面和接口资料 | 未提供 | 不能确认字段规则或 API 路由 |
| 产品会后回复 | 未提供 | 历史编辑、入口范围、空白处理待澄清 |

可开始：需求依据提取和问题整理。暂不能：将历史用户编辑规则写成定论，声称后端已经具备校验。

## 讲解检查点

让学员找出：哪些是业务材料，哪些需要代码证据？有材料不等于所有问题都已回答。
