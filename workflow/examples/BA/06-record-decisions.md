# BA 06｜记录共同决策：输入输出示例

[对应提示词](../../BA/06-record-decisions.md) · 实际工作模式：**Build**

> 合成教学样例，用于静态讲解；不是已执行记录或真实产品确认。

## 输入示例

输入 BA 05 的澄清核对稿，以及教学设定中采用的 P01—P09 产品回复。
示例要求：“归档当前采用的回复，保留问题编号；不要把仍缺的技术资料标成已验证。”

## 输出产物示例

### shared/decisions.md

完整样例见 [DEC-v1](../reference/decisions.md)。例如：
- DEC-01：管理端新增／编辑和对应保存 API；来源 P01。
- DEC-04：历史用户登录查询不变，但编辑保存必须补邮箱；来源 P04。
- DEC-06：校验失败不写入任何本次数据；来源 P07。

### ba/questions.md（增量）

Q-01 → DEC-01/08；Q-02 → DEC-02/03；Q-03 → DEC-04；
Q-04 → DEC-05；Q-05 → DEC-06；Q-06 → DEC-07。
状态均为“教学已答”。旧格式／唯一性规则明细另记 BLOCK-01：待核验。

### ba/decision-impact.md

DEC-04 影响 Story 的编辑场景、原型提醒、后端编辑校验、历史用户测试。
DEC-08 影响 DEV 的共享校验检查与 TEST 的范围外回归。
以上输出共享给 TEST；后续变更修改同一份 DEC，不分别造口径。

## 讲解检查点

保存决定是 Build；它只是登记已有回复，不赋予 Agent 业务决定权。
