# BA 03｜界定变更范围：输入输出示例

[对应提示词](../../BA/03-define-change-scope.md) · 实际工作模式：**Plan**

> 合成教学样例，用于静态讲解；不是已执行记录或真实产品确认。

## 输入示例

输入 BA 02 的 REQ-01—05 与现有系统说明。
已知：已有管理端页面，新增需要完整资料；没有新系统建设要求。
未知：编辑保存、个人资料与导入是否同改。

## 输出产物示例

### ba/change-scope.md

| 项目 | 当前案例设定 | 目标／本轮状态 |
|---|---|---|
| 管理端新增 | 邮箱可空 | 候选：新增要求邮箱 |
| 管理端编辑 | 可保留空邮箱 | 提醒还是强制补齐，待产品确认 |
| 对应保存 API | 现状未核验 | 候选：与页面业务规则一致 |
| 历史登录／查询 | 可正常使用 | 应保持；不得推导为停用或补造数据 |
| 个人资料／导入 | 有其他入口 | 范围待确认 |
| 手机号、通知系统 | 有关建议 | 本轮不承诺，记录后续事项 |

范围风险：若多个入口共用实体校验，局部改动可能波及其他入口。
阻塞：Q-01 范围、Q-02 空白、Q-03 历史编辑行为。
